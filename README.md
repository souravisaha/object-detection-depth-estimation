# Object Detection and Depth Estimation

## Overview
This project combines object detection and depth estimation using computer vision techniques.

## Features
- Detects objects in images or video.
- Estimates relative depth from visual input.
- Uses computer vision and deep learning models.

## Technologies
- Python
- OpenCV
- YOLO
- MiDaS

## Installation
1. Clone or download this repository.
2. Install the required dependencies:
   `pip install -r requirements.txt`
3. Run the appropriate Python script.

## How It Works
The object detection model identifies objects in the input, while the depth estimation model estimates the relative distance of objects from the camera.
